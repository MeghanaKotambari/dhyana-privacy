## Documentation Structure
- `index.html`: Unified single-page document containing Part A (Privacy Policy, `#privacy`) and Part B (Terms of Use, `#terms`).
- `privacy.html`: Lightweight redirect to `index.html#privacy`.
- `terms.html`: Lightweight redirect to `index.html#terms`.
- `.nojekyll`: Disables Jekyll processing on GitHub Pages to serve raw HTML directly.

## GitHub Pages Setup
If GitHub Pages is not already publishing from the root of `main`:
1. In the GitHub repository, navigate to **Settings > Pages**.
2. Under **Build and deployment > Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
